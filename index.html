    Where your data lives¶

    Tier Where Capacity Use it for Backed up?
    BeeGFS scratch /nvme + /nvme_vf 23.7 TB alignments, sorting, pipeline intermediates ❌ never
    Durable NFS /nfs_master, /Fungel 386 TB projects, reference genomes, final results organize your own copies
    Node-local /DATA on each node varies private fast scratch, single node only ❌ never

    The one rule

    Compute fast on scratch, keep the only durable copy on NFS. Anything on scratch or node-local disks can be deleted at any time.

    How work flows here¶

    1. Log in to master — prepare scripts and inputs there
    2. Check sinfo / squeue — see what's free before you plan
    3. Submit with sbatch — declare CPUs, memory, time, GPU
    4. Compute on node1–node3 or gpunode1 — never on master
    5. Save results to durable NFS — scratch is not storage
